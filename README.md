# 多摩祭2026 動画コンテスト

「スタート」を押すと動画がランダムな順番で1本ずつ流れ、見終わるたびにアンケート
（面白かった／面白くなかった、それぞれ何人か）に答える Web ページです。
全部流れると終了画面が出て、「スタートに戻る」で最初から始められます。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と動作 |
| `works.json` | 流す動画の一覧（ここに足すだけで本数が増える） |
| `config.js` | アンケートの送信先URLなどの設定 |
| `apps-script.gs` | アンケートを Google スプレッドシートに記録するスクリプト |

## 動画を登録する

1. 動画を共有の Google ドライブに置き、共有設定を **「リンクを知っている全員が閲覧可」** にする
   （これをしないと、サイト上で再生できません）
2. 動画のURLからファイルIDを取り出す
   `https://drive.google.com/file/d/`**`ここがID`**`/view`
3. `works.json` に1行足す

```json
{ "id": "w6", "title": "作品名", "author": "制作者名", "driveId": "ここがID" }
```

- `id` は作品ごとに重ならない文字列にしてください（集計に使います）。
- 本数は登録した数のまま動きます。
- 最初に入っている `DUMMY_` で始まる作品は動作確認用です。本番前に消すか、本物に差し替えてください。

> アップロード直後の動画は、Google ドライブ側の変換が終わるまで再生できないことがあります。
> 本番の前に、全作品がサイト上で再生できるか確認してください。

## アンケートの記録先を設定する

`config.js` の `SURVEY_ENDPOINT` が空のままだと、回答はスプレッドシートに送られず、
その端末のブラウザにだけ保存されます（動作確認用）。本番では次の手順で設定します。

1. Google スプレッドシートを新しく作る
2. メニュー「拡張機能」→「Apps Script」を開く
3. `apps-script.gs` の中身をすべて貼り付けて保存する
4. 関数 `setup` を選んで「実行」する（初回は権限の承認が出ます）
   → シート「回答」「集計」ができます
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
6. 発行された `https://script.google.com/macros/s/.../exec` を `config.js` の `SURVEY_ENDPOINT` に貼る
7. 変更をコミットして公開し直す

スクリプトを書き換えたときは、「デプロイを管理」から**新しいバージョン**でデプロイし直してください。
URLを知っている人は誰でも回答を送れます。URLは参加者に広めないでください。

回答は「回答」シートに1件ずつ追加され、「集計」シートで作品ごとの合計が見られます。

## 公開する（GitHub Pages）

リポジトリの Settings → Pages で、ブランチ `main`、フォルダ `/ (root)` を選びます。
表示されたURLを、スタッフのスマホとPCで開いてください。

## 手元で確認する

`works.json` を読み込むため、ファイルを直接開くのではなく簡易サーバーで開いてください。

```
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## 注意

- Google ドライブの埋め込みは、動画が終わったことをページ側から検知できません。
  そのため、見終わったら「アンケートに答える」を押す形にしています。
- 多くの人が同時に同じ動画を再生すると、ドライブ側の制限で再生できなくなることがあります。
  会場の上映など確実に流したい場面では、動画ファイルをPCに保存して流す方法も用意しておくと安心です。
